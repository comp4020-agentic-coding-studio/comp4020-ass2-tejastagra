# Reflection - Assignment 2

## The breakthrough

The breakthrough was splitting my harness by decision. CLAUDE.md had grown so large that its rules started working against each other, and the agent would only admit it had broken one after the work was done. I split it into separate files for content, deck design, course structure and decision-making [`ae278ee`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-tejastagra/commit/ae278ee), [`0302246`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-tejastagra/commit/0302246). After that, each task only had to reason against the file that applied to it and the output got noticeably better.

## What this changed about me as a developer

I want to be more experimental in how I approach my work. I found the split harness idea by chance on Twitter and had never tried anything like it. It turned out to be the most useful change I made in the whole assignment. I should try the ideas I read online more often and find out for myself whether they work.
