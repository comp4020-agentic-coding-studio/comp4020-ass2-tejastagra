Follows the [week 3 lecture](/lectures/week-03/) on vague asks and the
three-question rubric. This week's sync is led by Naomi Reyes.

## Exercise: run the rubric (30 min)

Take three asks from cold emails you've sent or received (a meeting
request, an investment ask, a favour). Run each through the lecture's
three-question rubric and mark which questions each one fails.

## Exercise: reprice the failures (30 min)

For any ask that failed a question, rewrite it so it passes all three,
without changing what's actually being requested — only how it's priced.
Compare the before and after side by side.
